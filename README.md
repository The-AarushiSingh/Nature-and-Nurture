# Nature & Nurture

**Nature & Nurture** is an AI-powered medicinal plant discovery and cultivation platform that combines a curated botanical knowledge base with Retrieval-Augmented Generation (RAG) to deliver accurate, source-grounded guidance on medicinal plants. Users can explore plants through advanced search and filters, receive personalized recommendations, identify plants and diseases from images, compare species, and manage a personal medicinal garden—all through a modern full-stack web application.

### ✨ Features

* 🌿 Explore a curated medicinal plant database with advanced search & filtering
* 🤖 RAG-powered AI assistant for reliable, source-grounded answers
* 🎯 Personalized plant recommendations based on user preferences and growing conditions
* 📷 AI-powered plant identification and disease diagnosis from images
* 🌱 Personal "My Garden" to save and manage favorite plants
* ⚖️ Side-by-side plant comparison
* 🔐 Secure user authentication
* 📱 Fully responsive, modern UI

### 🛠️ Tech Stack

* **Frontend:** Next.js, React, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas (with Vector Search)
* **AI:** OpenAI API (Chat, Embeddings, Vision)
* **Deployment:** Vercel + MongoDB Atlas

### 🚀 Vision

Nature & Nurture aims to bridge traditional Ayurvedic medicinal plant knowledge with modern AI, making plant discovery, cultivation, and care more accessible through intelligent recommendations and trustworthy, retrieval-augmented assistance.
